Academic Project Page Skill

An agent skill that turns a folder of paper, figures and videos into a polished, checked academic project page, then audits it for contrast, links, numbers and layout before handing it over.

npx skills add royh1122/academic-project-page-skill

View on GitHub

Three live demos

The demo projects, people, institutions and results are fictional (the “Quillwave” example kit). Each page was built in one run of the skill, with no edits afterwards.

  • Accepted paper

    A published paper with every link: paper, code, video, poster and results.

    Open demo, accepted paper

  • Research in preparation

    Work not yet released: no public links, and nothing invented to fill the gap.

    Open demo, research in preparation

  • Final-year project

    A student project with a verified award, report and video.
