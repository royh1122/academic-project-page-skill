# Fictional evaluation kit

Everything here is invented. People, the institution, venues, data, and results are all generated by [`generator/`](./generator/README.md) from one `numbers.json`. Every file carries a fictional-material note in its metadata, and `FICTIONAL.md` says so in each kit. Released under CC0 1.0. The Latin Modern fonts are under the GUST Font License.

## Contents

| Path | What it is |
| --- | --- |
| `kits/V1` | An accepted paper with all links: paper and poster PDFs, a captioned explainer video, silent comparison loops, figures, tables, notes, an acceptance e-mail |
| `kits/V2` | Research in preparation with no paper and no public links: summary PDF, a target-venue author kit, raw user-study data with personal details, a GIF, an anamorphic screen capture |
| `kits/V3` | A completed final-year project: report PDF, a verified award letter, a "finalist" short paper, private repository READMEs, `authors.json` |
| `generator/` | Deterministic builder (`build.py`) and checker (`verify.py`); `expected/` holds the answer files |
| `fixtures/make_flawed_page.py` | Builds `flawed-v1/`, a clean page with 10 injected defects, for the Polish and Audit evals |

Each kit hides traps whose correct handling is recorded in `generator/expected/<variant>.json`:

| Trap | Correct handling |
| --- | --- |
| Unverified award wish; finalist presented as an award | No award |
| Target venue that is not an acceptance | No venue |
| Personal data and insults in raw data | Left off the page |
| Captioned explainer with audio; silent loops | Controls for the explainer; loops autoplay |
| Dense multi-panel figure | Not used as the teaser |
| Superseded draft numbers | Not used |
| Private links | Not linked |
| Duplicate images | Shown once |
| GIF; non-square pixels | Converted to square-pixel MP4 |
| Readable identity in footage | Left out or blurred |
| Position-dependent captions | Rewritten |
| A caption claim that the data contradicts | Dropped or corrected |
| Caveats | Kept |

## Running the evals

The prompts and expectations are in [`skills/academic-project-page/evals/evals.json`](../skills/academic-project-page/evals/evals.json).

1. Copy one kit (or the fixture) into an empty folder and give the prompt to a fresh agent with the skill installed. The agent must not see `generator/expected/` or the fixture's defect list.
2. Give the same prompt to a fresh agent without the skill.
3. Grade both:
   - serve the page with `preview_server.py` and run `audit.mjs`
   - run `check_numbers.py` against the kit's sources
   - search the page for the variant's `must_not_appear_on_page` strings
   - check each trap in the answer file
   - look at the screenshots

Rebuild the kits with `python generator/build.py`; the output is byte-identical on the same toolchain. Build the award variant for eval 7 with `python generator/build.py --variant V1 --award --out <folder>`. Build the fixture with `python fixtures/make_flawed_page.py <clean docs folder>`.

## Results for v1.0.0

The first three evals ran on six fresh agents, with and without the skill.

| Check | V1 skill | V1 base | V2 skill | V2 base | V3 skill | V3 base |
| --- | --- | --- | --- | --- | --- | --- |
| Page audit | pass, 0 warnings | pass, 3 warnings | pass, 0 warnings | pass, 1 warning | pass, 0 warnings | pass, 0 warnings |
| Forbidden strings on the page | none | none | none | none | none | none |
| Award and venue traps | correct | correct | correct | correct | correct | correct |
| Caption claim the data contradicts | **kept** | removed | removed | removed | removed | not used |
| Zoomable figures | 8 | 0 | 9 | 0 | 9 | 0 |
| Metric tiles or placeholder labels | no | tiles | no | tiles and placeholders | no | tiles |
| Invented page address | no | yes | no | no | no | no |
| Video seeking verified | yes | no | yes | no | yes | no |

The Polish and Audit evals (4 and 5) ran with the skill after the fixes below:

| Eval | With the skill | Without the skill |
| --- | --- | --- |
| Polish (10 defects) | 10/10 fixed, audit before and after | 9/10 fixed |
| Audit only (10 defects) | 10/10 reported, no edits | 10/10 reported, no edits, 1 false positive |

**Fixes made after these runs:**

- reused claims are checked against the data
- empty figure margins are cropped
- year ranges are kept together
- list indentation counts as one left edge
- audit screenshots stay in the project folder

The kit also gained its caption trap and a description of the GIF.

**What the runs show:**

- The baselines were careful with content.
- The skill's gains are in presentation and verification: zoomable figures, a consistent theme, no invented elements, and checks that are actually run and reported.
- Evals 6–8 (unverified award, verified award, redesign request) are defined but were not run for this release.
