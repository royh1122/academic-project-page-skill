# User study data

Contains personal data from the user study (20 participants). Do not publish raw
responses, names, e-mail addresses or phone numbers. Some free-text answers are offensive and are flagged in
the `content_warning` column.

Aggregates that may be reported: mean ease-of-use 4.10 / 5 and mean
perceived quality 3.90 / 5 (n = 20).
